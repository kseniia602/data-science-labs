# Лабораторна робота №5
## Наука про дані: обмін результатами та початковий аналіз

### Опис завдання
Створення веб-додатку із використанням модуля **Streamlit** для візуалізації та інтерактивного аналізу даних VCI, TCI, VHI, отриманих у ході виконання Лабораторної роботи №2. Додаток дозволяє користувачу налаштовувати фільтри та переглядати результати у вигляді таблиць та графіків.

### Основні можливості
* Вибір часового ряду (VCI, TCI, VHI) через dropdown.
* Вибір області України для аналізу.
* Слайдери для вибору інтервалу тижнів та років.
* Кнопка скидання всіх фільтрів до початкового стану.
* Сортування даних за зростанням/спаданням за допомогою чекбоксів.
* Три вкладки для відображення: Таблиця з даними, Графік динаміки, Порівняння областей.

### Вимоги до системи
* Python 3.9+
* Streamlit
* Pandas
* Matplotlib / Seaborn

### Встановлення залежностей
python -m venv venv
pip install -r requirements.txt

### Структура
* app.py — основний файл веб-додатка на Streamlit.
* vhi_all_provinces.csv — набір даних для аналізу (результат ЛР №2).
* requirements.txt — список необхідних бібліотек.
