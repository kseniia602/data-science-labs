# Лабораторна робота №4
## Інтерактивна візуалізація гармоніки з фільтрацією шуму

## Опис завдання
Ця лабораторна робота присвячена інтерактивній візуалізації функції гармоніки виду `y(t) = A·sin(ωt + φ)` з накладеним шумом та подальшою фільтрацією сигналу. Реалізовано повноцінний інтерактивний інтерфейс із слайдерами, чекбоксами та кнопкою скидання параметрів.

## Структура програми

### Клас `HarmonicGenerator`
Відповідає за генерацію сигналу та шуму:
* `harmonic(amplitude, frequency, phase)` — генерує чисту гармоніку
* `generate_noise()` — генерує шум із заданими параметрами
* `apply_filter(signal_data, cutoff_freq)` — застосовує фільтр Баттерворта 4-го порядку
* `reset_params()` — відновлює початкові параметри

### Клас `InteractiveHarmonic`
Відповідає за інтерфейс та відображення:
* `create_widgets()` — створює всі елементи керування
* `on_harmonic_change()` — оновлює графік при зміні параметрів гармоніки (шум не змінюється)
* `on_noise_change()` — генерує новий шум при зміні його параметрів
* `reset()` — відновлює всі початкові значення
* `update_plot()` — перемальовує графіки через Plotly

## Інтерфейс користувача
## Інтерфейс користувача

### Слайдери
| Слайдер | Діапазон | Початкове значення | Опис |
|---------|----------|-------------------|------|
| Амплітуда | 0.1 – 2.0 | 1.0 | Амплітуда гармоніки |
| Частота | 0.1 – 5.0 | 1.0 | Частота гармоніки (Гц) |
| Фаза | 0.0 – 6.28 | 0.0 | Фазовий зсув (рад) |
| Середнє шуму | -0.5 – 0.5 | 0.0 | Середнє значення шуму |
| Дисперсія шуму | 0.0 – 0.5 | 0.1 | Стандартне відхилення шуму |
| Частота зрізу | 1.0 – 20.0 | 5.0 | Частота зрізу фільтра (Гц) |

### Чекбокси
* **Показати шум** — показати/сховати зашумлений сигнал на графіку
* **Показати фільтр** — показати/сховати відфільтрований сигнал

### Кнопка
* **🔄 Reset** — повертає всі параметри до початкових значень

## Графіки

### Верхній графік — Оригінальний сигнал
* **Чиста гармоніка** — синя лінія
* **Зашумлений сигнал** — помаранчева лінія (вмикається через "Показати шум")

### Нижній графік — Відфільтрований сигнал
* **Відфільтрований сигнал** — зелена лінія
* **Чиста гармоніка (еталон)** — синя пунктирна лінія для порівняння

---

## Фільтр
Використовується **фільтр Баттерворта низьких частот 4-го порядку** (`scipy.signal.butter` + `scipy.signal.filtfilt`):
* Параметр **Частота зрізу** задає частоту зрізу
* Менше значення = більше згладжування
* `filtfilt` застосовує фільтр у двох напрямках — нульова фазова затримка

## Важливі особливості реалізації
 Зміна параметрів **гармоніки** → шум залишається незмінним  
 Зміна параметрів **шуму** → генерується новий шум, гармоніка не змінюється  
 Під час **Reset** observers тимчасово вимикаються, щоб уникнути зайвих викликів перемальовування  
 Використано **Matplotlib** для стабільного відображення графіків у Jupyter  
 Детальні інструкції українською мовою безпосередньо в інтерфейсі програми
