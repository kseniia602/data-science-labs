# Лабораторна робота №2

## Опис завдання
**Частина 1:** Завантаження та аналіз VHI-індексу для областей України
**Частина 2:** Аналіз датасету Individual Household Electric Power Consumption

## Вимоги до системи
- Python 3.8+
- Jupyter Notebook

## Встановлення залежностей
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск
```bash
jupyter notebook
```

## Структура
- `part1.ipynb` - VHI аналіз
- `part2.ipynb` - Electric Power аналіз
- `requirements.txt` - залежності
