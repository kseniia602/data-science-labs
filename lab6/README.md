# Лабораторна робота №6
## Обробка відео в реальному часі з використанням OpenCV та C++

### Опис завдання
Створення C++ програми з модульною архітектурою для захвату відеопотоку з веб-камери, його відображення в інтерактивному вікні та застосування різних фільтрів обробки зображення в реальному часі. Проєкт реалізований із використанням бібліотеки **OpenCV** та системи збірки **CMake**.

### Основні можливості
*   **Модульна архітектура**: Логіка розділена на класи (`CameraProvider`, `FrameProcessor`, `KeyProcessor`, `Display`), кожен з яких має власні `.hpp` та `.cpp` файли.
*   **Інтерактивне керування**: Перемикання режимів обробки за допомогою клавіатури (клавіші 1-5).
*   **Режими обробки (Фільтри)**:
    *   `1` — Звичайне відображення.
    *   `2` — Інверсія кольорів (негатив).
    *   `3` — Canny фільтр (виявлення контурів).
    *   `4` — Gaussian Blur (розмиття зображення).
    *   `5` — Glitch ефект (маніпуляція кольоровими каналами).
*   **Інформаційна панель**: Відображення тексту з інструкціями поверх відеопотоку.

### Вимоги до системи та заліза
*   **Операційна система**: Ubuntu 22.04 LTS (або інша Linux-сустема з підтримкою X11/Wayland).
*   **Залізо**: Веб-камера (інтегрована або зовнішня USB-камера).
*   **Бібліотеки**: OpenCV 4.x (libopencv-dev).
*   **Компілятор**: GCC/G++ з підтримкою стандарту C++17.
*   **Інструменти**: CMake (версія 3.10+), Make.

### Встановлення та запуск (Інструкція для Linux)
Для автоматизації процесу білду та запуску використовуються Bash-скрипти:

1.  **Встановлення залежностей** (OpenCV, CMake, GCC):
    ```bash
    chmod +x preinstall.sh
    sudo ./preinstall.sh
    ```
2.  **Компіляція проєкту**:
    ```bash
    chmod +x build.sh
    ./build.sh
    ```
3.  **Запуск програми**:
    ```bash
    chmod +x run.sh
    ./run.sh
    ```

### Структура проєкту
*   `include/` — заголовні файли класів (.hpp).
*   `src/` — файли реалізації логіки та функція `main()` (.cpp).
*   `CMakeLists.txt` — конфігураційний файл для системи збірки CMake.
*   `preinstall.sh`, `build.sh`, `run.sh` — скрипти для швидкого розгортання та запуску.
*   `README.md` — опис проєкту та інструкції.
