# Лабораторна робота №7
## Computer Vision та багатопотоковість у C++

### Опис проєкту
Ця програма є розширенням попередньої лабораторної роботи. Основна мета — реалізація асинхронної детекції облич за допомогою глибоких нейронних мереж (**OpenCV DNN**) та багатопотокового програмування. Проєкт реалізовано на рівні 2 (Поглиблений), що забезпечує плавне відео без затримок інтерфейсу.

### Архітектура та класи
Проєкт має модульну структуру, де кожен клас відповідає за окрему задачу:

1.  **`CameraProvider`**: Забезпечує стабільний захват відеопотоку з веб-камери (індекси 0 або 1).
2.  **`KeyProcessor`**: Обробляє введення з клавіатури. Додано підтримку режиму `FACE` (клавіша 'F').
3.  **`FrameProcessor`**: Реалізує класичні фільтри обробки зображень (Інверсія, Canny, Blur, Glitch).
4.  **`Display`**: Створює графічне вікно та відображає фінальний результат обробки.
5.  **`FaceDetector` (Головний модуль ЛР №7)**:
    *   Працює в окремому фоновому потоці (**`std::thread`**).
    *   Використовує модель **ResNet-10 (SSD)** для пошуку облич.
    *   Синхронізує дані з основним потоком за допомогою **`std::mutex`** (м'ютексів).
    *   Забезпечує асинхронність: важкі обчислення нейромережі не блокують оновлення відео (UI).

### Вимоги до системи
- **ОС**: Linux (Ubuntu 22.04+).
- **Бібліотеки**: OpenCV 4.x (модулі core, videoio, highgui, imgproc, dnn).
- **Залізо**: Веб-камера, процесор з підтримкою багатопотоковості.
- **Компілятор**: G++ (стандарт C++17).

### Інструкція зі збірки та запуску
Для зручності розгортання на "чистій" системі використовуються Bash-скрипти:

1.  **Попереднє налаштування та завантаження нейромережі**:
    Цей скрипт встановить необхідні пакети та автоматично завантажить файли моделі (`deploy.prototxt` та `.caffemodel`).
    ```bash
    chmod +x preinstall.sh
    ./preinstall.sh
    ```

2.  **Збірка проєкту (CMake)**:
    ```bash
    chmod +x build.sh
    ./build.sh
    ```

3.  **Запуск програми**:
    ```bash
    chmod +x run.sh
    ./run.sh
    ```

### Керування програмою
- **`1` — `5`**: Перемикання класичних фільтрів обробки.
- **`F` / `f`**: Увімкнення/вимкнення режиму детекції облич.
- **`ESC`**: Завершення роботи програми та безпечна зупинка фонових потоків.

### Особливості реалізації (Рівень 2)
Завдяки винесенню `net.forward()` в окремий потік `Worker Thread`, основне відео залишається плавним (30-60 FPS). Координати знайдених облич оновлюються асинхронно, що дозволяє уникнути "завмирання" картинки під час важких обчислень нейромережі.
